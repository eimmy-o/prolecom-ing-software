
##User Stories 

##Student 

| **ID**        | **User Story**                                                                                                                     | **Requerimientos relacionados** |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| **US-STU-01** | As a student, I want to register and log into the platform using my username and password so I can access my courses.              | RF-01                           |
| **US-STU-02** | As a student, I want to see a home page that shows my enrolled courses and allows me to navigate easily through them.              | RF-02                           |
| **US-STU-03** | As a student, I want to enroll in one or more available courses so I can access their materials and activities.                    | RF-03                           |
| **US-STU-04** | As a student, I want to post questions in the general forum of a course so I can get help from others.                             | RF-04                           |
| **US-STU-05** | As a student, I want to view and reply to other users’ questions in the course forum so I can participate in academic discussions. | RF-05                           |
| **US-STU-06** | As a student, I want to report posts that violate the platform’s rules or guidelines so moderators can review them.                | RF-06                           |
| **US-STU-07** | As a student, I want to view the learning materials uploaded by the professor so I can study and review course content.            | RF-07                           |
| **US-STU-08** | As a student, I want to access a bank of programming challenges organized by difficulty so I can practice progressively.           | RF-08                           |
| **US-STU-09** | As a student, I want to solve coding challenges directly in the integrated IDE so I can test my code without external tools.       | RF-09                           |
| **US-STU-10** | As a student, I want to receive automatic feedback on common coding errors so I can understand and fix my mistakes.                | RF-10                           |
| **US-STU-11** | As a student, I want to see my progress and ranking in the course leaderboard so I can track my improvement and motivation.        | RF-11                           |
| **US-STU-12** | As a student, I want to take quizzes or short assessments created by the professor so I can test my knowledge on each topic.       | RF-12                           |
| **US-STU-13** | As a student, I want to generate flashcards based on quiz questions to study and reinforce my learning.                            | RF-13                           |
| **US-STU-14** | As a student, I want to communicate directly with professors and assistants through a messaging feature so I can ask for help.     | RF-14                           |


##Professor 

| **ID**         | **User Story**                                                                                                                                     | **Requerimientos relacionados** |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| **US-PROF-01** | As a professor, I want to upload, edit, and organize learning materials by topic within a course so that students can access structured resources. | RF-P01                          |
| **US-PROF-02** | As a professor, I want to create courses that can be public or private so I can control who has access to the content.                             | RF-P02                          |
| **US-PROF-03** | As a professor, I want to create, edit, and delete programming exercises so I can assign challenges to my students.                                | RF-P03                          |
| **US-PROF-04** | As a professor, I want to answer students’ questions in the forum so I can clarify academic doubts.                                                | RF-P04                          |
| **US-PROF-05** | As a professor, I want to report posts that violate the platform’s academic rules so moderators can review them.                                   | RF-P05                          |
| **US-PROF-06** | As a professor, I want to communicate directly with students and assistants through messages so I can provide guidance and feedback.               | RF-P06                          |
| **US-PROF-07** | As a professor, I want to review and test programming challenges to ensure they work correctly and align with the learning objectives.             | RF-P07                          |
| **US-PROF-08** | As a professor, I want to add one or more teaching assistants to a course so they can help me manage content and student interactions.             | RF-P08                          |
| **US-PROF-09** | As a professor, I want to generate invitation links for private courses so selected students or assistants can join.                               | RF-P09                          |
